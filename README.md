# 🎨 Frontend Ruiz - Sistema de Gestión de Personas

Interfaz administrativa moderna desarrollada en Angular 18 para la gestión de personal. Este proyecto consume la API REST del backend para ofrecer una experiencia CRUD completa y fluida.

---

## 🛠️ Tech Stack

- Framework: Angular 18
- Estilos: Bootstrap 5
- Formularios: Reactive Forms
- Cliente HTTP: HttpClient (Angular)
- Iconografía: FontAwesome / Bootstrap Icons

---

## ⚙️ Configuración e Instalación

### 1. Requisitos Previos

- Node.js v18+
- Angular CLI v18
- Backend activo en: http://localhost:8080

### 2. Despliegue Local

git clone https://github.com/tonysoft2018/tesffullstack
cd tesffullstack
git checkout ruiz_frontend
cd ruiz_frontend

### 3. Instalación de Dependencias

npm install

### 4. Ejecución

ng serve

La aplicación estará disponible en: http://localhost:4200/persons

---

## 🚀 Características Principales

- Listado Dinámico: Consumo eficiente de datos mediante ResponseDTO.
- CRUD Operacional: Gestión completa de registros (Crear, Leer, Actualizar, Borrar).
- Validaciones Proactivas: Formularios reactivos con validación de datos en tiempo real.
- Date Management: Manejo de fechas con calendario nativo y formato dd-MM-yyyy.
- Responsive Design: Interfaz adaptativa construida con Bootstrap 5.

---

## 🛣️ Rutas del Sistema

- /persons -> Dashboard principal con tabla de registros.
- /person/new -> Formulario de alta de nuevo personal.
- /person/edit/:id -> Vista de edición para registros existentes.
